# KwDig Markdown Paste 1.0.7

WordPressへMarkdownを貼り付ける際、行末の半角スペース2個による明示的改行と、空行による段落区切りを正しく変換する無料プラグインです。クラシック／ブロックエディターの専用「Markdown貼り付け」と、通常のCtrl+Vに対応します。

[インストール用ZIP（v1.0.7）](https://github.com/kwdig/kwdig-markdown-paste/releases/download/v1.0.7/markdown-paste-linebreaks.zip) ／ [紹介ページ](https://kwdig.com/kwdig-markdown-paste)

## 改行仕様

| Markdownの入力 | 変換結果 |
| --- | --- |
| 行末の半角スペース2個以上＋改行 | 同じ段落内で`<br>` |
| 通常の改行 | 同じ段落内の空白。強制改行しない |
| 空行 | 別の`<p>`段落 |
| 行末のバックスラッシュ＋改行 | Markdown標準の明示的改行（`<br>`） |

通常の改行は、WordPressの自動整形で`<br>`へ戻らないよう、変換時に空白へ正規化します。画面幅による自然な折り返しは発生します。段落の`<p>`は正常な出力です。

**1.0.6以前との違い：** すべての改行・空行を`<br>`にする既定動作を廃止しました。専用ダイアログの旧チェック項目もなくなり、Markdown標準の扱いに統一しています。既存記事を自動で一括変更する機能はありません。

## インストール・更新

1. 上記のインストール用ZIPをダウンロードします。解凍は不要です。
2. WordPress管理画面の「プラグイン → 新規追加 → プラグインのアップロード」でZIPを指定します。
3. 初回はインストール後に有効化します。旧版がある場合は表示される置換・更新の案内に従います。
4. 記事編集画面を再読み込みしてから使います。

WordPress 6.0以上、PHP 7.4以上。マルチサイトへのインストールはネットワーク管理者が行います。GitHubの「Code → Download ZIP」はリポジトリ全体です。WordPressへのインストールにはリリース添付の`markdown-paste-linebreaks.zip`を使ってください。

## 通常のCtrl+V

本文の挿入位置でMarkdownを貼り付けます。クラシックのビジュアル／テキスト欄、ブロックエディターの段落に対応します。見出し・複数段落などはカスタムHTMLブロックとして挿入する場合があります。

タイトル欄、コード欄、HTMLブロック、複数ブロックをまたぐ選択は自動変換の対象外です。Markdown記号のない書式付きクリップボードはWordPress標準の貼り付け処理に渡します。

## 専用「Markdown貼り付け」

- クラシック：本文上の「Markdown貼り付け」を開きます。
- ブロック：右上の「︙（オプション）」から「Markdown貼り付け」を開きます。
- Markdownを入力し、「変換後のHTML」で確認して「記事へ挿入」を押します。
- 表示を確認して下書き保存します。ブロックでは選択したブロックの後ろへ挿入し、既存ブロックを置き換えません。

## 脚注リンクの例

次のコード例の1・2行目の末尾には半角スペースを2個入れています。

```markdown
[1] [Schema.org](https://schema.org/)  
[2] [BlogPosting](https://schema.org/BlogPosting)  
[3] [Google公式資料](https://developers.google.com/search/docs/appearance/structured-data/intro-structured-data)
```

3件のリンクが1つの段落内で並び、行間は`<br>`2個になります。脚注同士に空行を入れた場合は別段落になります。リンクの中へリンクが二重化した番号付き脚注は、重複URLがすべて同じ場合に限って補正します。コード内や異なるURLは補正しません。

## Googleドキュメント → GAS

編集画面のCtrl+V処理はGASからの送信には実行されません。このプラグインをインストールするだけで、あらゆるGAS連携へ適用されるわけではありません。

今回使用したGoogle Docs変換用のGASランタイムとアダプターを`integrations/google-docs/`に同梱しています。既存GASへの組み込み方法と前提条件は、そのフォルダーのREADMEを参照してください。書式のない連続テキストをMarkdownとして扱い、Google Docsのネイティブ見出し・太字・リンク・表などは既存のHTML変換処理へ渡します。

## 保存・再読み込みの確認結果

2026年11月10日、kwdig.comのブロックエディターで通常のCtrl+Vから下書き保存し、再読み込み後も次の結果を確認しました。Googleドキュメント→GAS→WordPressの経路も、別の検証用下書きで同じ結果でした。

| 確認内容 | 通常のCtrl+V | Google Docs→GAS |
| --- | --- | --- |
| 通常の改行 | 同じ段落・BRなし | 同じ段落・BRなし |
| 行末半角スペース2個 | 同じ段落内にBR1個 | 同じ段落内にBR1個 |
| 空行 | 別々のP段落 | 別々のP段落 |
| 脚注3リンク | 保持 | 保持 |

検証記事は下書きのままです。クラシックの挿入経路は自動テストを実施していますが、v1.0.7の保存・再読み込みの実画面確認は上記の2経路です。

## テスト

Node.js 24で確認。開発用依存関係をインストールし、実行します。WordPress本番でNode.jsは不要です。

```sh
npm install
npm test
```

標準のsoft/hard break、空行、CRLF、脚注補正、コード、危険なHTML/URL、挿入位置の前後文、GASアダプターを検証します。通常表示のフロント側にはプラグインのJavaScriptやCSSを追加しません。Markdownの生HTMLは実行せず文字として扱います。画像の取り込み機能はありません。
